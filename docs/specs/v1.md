# Air guitar v1 spec

A browser instrument: stretch strings in the air with your hands (webcam + MediaPipe), pluck them with your fingertips. A typed, modular TypeScript rewrite of Hashem Al-Ghaili's Music Maker, simplified and changed per David's wishes below. Kids play it too, so nothing may depend on timing or holding still.

## Changes from Music Maker

1. **Up to eight hands** (`numHands: 8`). Every gesture works per hand, independent of which person it belongs to. Watch frame rate; degrade gracefully.
2. **One sound per string.** A string plays one pitch, set by its length (shorter = higher, like a real string; pitch ∝ 1/length). No notes along the string, no chords mode. Where you cross it doesn't change the pitch. Changing length (moving an end) changes the pitch.
3. **Key and tone stay, reinterpreted:** the length→pitch mapping snaps to the nearest note of the selected key + scale, so every string sounds in key. Add a "Free" tone option (no snapping, continuous pitch). Global, in the top bar.
4. **Build / Mixed / Play modes** (a three-way segmented control in the top bar, SVG icons; keys B, M, P, ignored while typing or with a dialog open).
   - Build: create strings, grab and move endpoints, delete, change a string's instrument. Plucking still works.
   - Mixed: grab and move endpoints (resizes and re-pitches), pluck, rest-to-hold, and pinch-on-string bend (the middle bends, as in Play). No creating, deleting, or instrument changes: dropping an end on the other end keeps a minimum length instead of deleting.
   - Play: play only. No creating, moving, deleting, or instrument changes. Pinch-on-string bend is fine in Play since it doesn't change the layout.
   - Up to 32 strings on the stage; string voices are capped (oldest stolen) so a full stage stays smooth.
5. **No radial string menu** (Instrument/Tone/Key/Chords/Lower/Higher/Remove/Done). Instead, in Build mode:
   - Pinch in empty space with two hands and pull apart → new string (as in Music Maker).
   - Pinch near an endpoint → grab that node, move it, release to drop.
   - Drop an endpoint onto the other endpoint of the same string → the string is deleted (with a small visual/sound cue).
   - Pinch the middle of a string → opens the instrument picker (Music Maker's grid: same SVGs, colors, layout).
   - A new string (hands or mouse) opens the picker on itself right away, with the top bar's instrument (which it already plays) shown as picked; closing keeps it.
6. **Instrument picker without timers.** Selecting needs a pinch on an instrument tile. No dwell-to-select, no auto-close countdown (remove the spinner). Close with a pinch outside the panel or on a close button. Mouse: click.
7. **No bottom bar.** Everything goes in one top bar, as tall as Music Maker's, one line. Use SVG icons (with tooltips/`aria-label`) in place of text labels so it fits.
   - Beat selector → a dropdown.
   - Beat parts (kick, snare, hats, bass, chords) → one dropdown with checkboxes.
   - Removed: layer recording / looper, "Follow chords".
8. **Dark theme only.** Drop the light theme.

## Keep from Music Maker

- Design: fonts, colors, spacing, glow, particles, the overall look.
- The instruments (all 24, synthesized, no samples), Karplus–Strong for plucked strings.
- Recording: video with sound, sound only, landscape/vertical, MP4/WebM, MP3, WAV, beat-part stems.
- Beats (the pre-made patterns, look-ahead scheduler on the audio clock).
- Settings, Help, Setups (save/load a whole stage; ready-made layouts).
- Autosave: a reload or reopen restores the last session (strings, key, tone, shape, mode, beat, parts, tempo; sound sliders are settings). A corrupt or old save falls back to the empty stage.
- Mouse mode ("Play with the mouse instead"), for testing.
- Pinch-on-string bend in Play mode, rest-finger sustain: keep if they don't clash with the gestures above. Music Maker's empty-air filter/echo sweep is dropped; its Tone and Echo are sliders in the top bar instead.

## Code quality

- Vite + TypeScript strict, pnpm, mise-pinned Node. Small modules by concern: `tracking/`, `gestures/`, `strings/` (model), `render/`, `audio/` (engine, worklets, instruments, beats, reverb), `ui/` (top bar, picker, dialogs), `record/`, `setups/`, `state`.
- Pure logic unit-tested with Vitest (pinch hysteresis, crossing detection, length→pitch + scale snapping, endpoint grab/merge-delete, mode rules).
- Strong linting (oxlint and/or ESLint strict-type-checked), oxfmt formatting, a `./scripts/check` (or `pnpm check`) that runs format check, lint, typecheck, tests, build. Model it on David's other projects (Cmdr's checker is the gold standard: `~/projects-git/vdavid/cmdr/scripts/check/`; `~/projects-git/vdavid/lujza` is the closest small sibling).
- lamejs: use the npm package if a maintained one exists, else vendor it in its own file with its LGPL notice. Don't paste it into app code.
